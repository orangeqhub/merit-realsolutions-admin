# Merit Real Solutions Admin Portal

Internal ERP for venture management, plot inventory, reservations, channel partners, and sales operations.

## Setup

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Scripts

| Command | Description |
|---------|-------------|
| `npm run dev` | Start development server |
| `npm run build` | Production build |
| `npm run sync-data` | Sync ERP relationship data |
| `npm run gen-engagement` | Generate engagement mock data |
| `npm run gen-reservations` | Generate reservation mock data |

## Stack

React 19, Vite, React Router, Framer Motion, LocalStorage data layer.
